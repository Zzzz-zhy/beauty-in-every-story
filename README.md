# BEAUTY IN EVERY STORY · 展示端前端

基于已确认的欧莱雅故事展览馆 Figma 设计，使用 Next.js App Router、React、TypeScript、CSS Modules 与 Motion 实现。白色/冷灰页面、品牌灰褐色胶囊按钮与官网卡片阴影保持一致。

## 本地运行

需要 Node.js 20.9 或以上版本。

```sh
npm ci
npm run dev
```

打开 http://localhost:3000 。生产预览：

```sh
npm run build
npm start
```

## 已实现的页面与流程

- `/`：官网风格入口，链接到故事展览和项目说明。
- `/stories`：8 个故事的展墙、精选故事、卡片反馈与进入详情过渡。
- `/stories?view=list`：搜索、情绪筛选、排序、分页和可恢复的空结果。
- `/stories/[slug]`：独立故事链接、章节、系统语音朗读、分享和关联产品。
- `/products/[slug]`：产品与参考色号、官方链接、加入清单。
- `/selection`：选择产品、数量修改、清单摘要、本地保存，刷新后保留来源故事。
- `/shop-handoff`：地区选择、官方商品外链、复制和下载清单。
- `/impact`：筹备中的公益联动说明。
- 全局阅读设置：文字放大、对比度、动效偏好、默认浏览方式。
- 不可用故事、加载与错误恢复状态。

Figma 的分享成功、阅读设置与空结果设计分别实现为弹层/提示和页面状态，而不是没有上下文的独立页面。

## 动效

- 展墙首次入场及筛选重排使用 Motion。
- 卡片悬停上浮、封面微缩放、按钮反馈使用 CSS。
- 从展墙进入故事时，持久布局上的封面过渡层对齐详情主图并淡出；失败或超时会清除，不阻止导航。
- 返回展墙恢复 URL 筛选、页码、滚动位置和原入口焦点，包含列表中的“阅读 / 收听故事”按钮。
- 保留原生滚动与光标。移动端不依赖悬停。
- 系统减少动态效果和站内设置均生效；内容不会因关闭动画而隐藏。

## 数据与实际接入边界

本项目是可运行的前端概念体验。8 个故事是演示内容，AI 图片不代表真实参与者；产品图和链接参考 L’Oréal Paris 美国官网。

系统语音朗读使用浏览器 SpeechSynthesis，没有伪造正式录音、音乐或音频时长。设备不支持或播放失败时保留完整文字。正式音频可在后续内容接口中接入。

没有真实 CMS、用户账户、官方购物车或支付接口。清单保存在当前浏览器，官方商品在新标签打开；不会声称已将商品加入品牌购物车。公益比例和规则没有确定，页面明确保持筹备状态。

## 代码结构

- `src/app/`：路由、服务端页面、metadata 和错误状态。
- `src/components/`：品牌外壳、交互组件、动效、设置、分享与清单。
- `src/components/ui.module.css`：共享页面布局与组件样式。
- `src/app/globals.css`：设计变量、全局样式与阅读偏好。
- `src/lib/content.ts`：故事/产品类型与本地 Repository；可替换为 CMS/API。
- `public/images/`：本地原始素材，不依赖临时 Figma URL。
- `tests/`：主要流程与可访问性检查。

Noto Sans SC 与 Inter 字体通过 npm 包本地提供。图片由 Next Image 提供响应式优化；素材原图保留便于继续编辑。

## 部署

支持标准 Next.js Node 运行环境或兼容平台。运行 `npm run build` 后用 `npm start` 提供服务。当前保留 `robots: noindex`，适用于概念展示；正式发布前替换演示内容、配置网站域名和分享元信息，并接入实际内容与商城服务。
